# 客户工作台 v2 · 产品规格

> 作者：Claude（产品/设计/验收）。实现：Codex。
> 本文件是新版的唯一产品依据。旧版代码与旧数据全部废弃，不做兼容、不做迁移。

## 1. 一句话定位

一个人接单做设计/创意服务的自由职业者，用来管理 **客户 → 项目 → 文件 → 收款** 的 Windows 本地桌面应用。打开就知道今天该做什么、谁还没付钱、某个客户以前做过什么。

## 2. 用户与场景

- 用户：个人设计师/工作室主理人，客户主要来自淘宝、闲鱼、小红书、微信转介绍。
- 每天：查看今天到期/逾期的活 → 打开项目 → 把设计稿拖进项目 → 记沟通/改稿意见 → 改状态 → 收到钱记一笔。
- 经常：复制客服话术发给客户；按标签找一类客户（比如「老客户」「餐饮」「难缠」）；月底看收入。
- 偶尔：找半年前给某客户做的源文件。

## 3. 核心概念

| 概念 | 说明 |
|---|---|
| 客户 Client | 一个人或一家店。联系方式、平台账号、标签、星级、备注、客户资料文件夹。 |
| 项目 Project | 给某个客户做的一单活（一张海报、一套品牌、一次改稿都可以）。有状态、截止日、报价、成本、收款、文件、动态。 |
| 标签 Tag | 全局统一管理、带颜色。客户和项目都可以打。 |
| 收款 Payment | 挂在项目下，可多笔，可退款。 |
| 动态 Activity | 项目/客户的时间线：手写备注 + 系统自动记录（状态变更、收款、新增文件、创建）。 |
| 话术 Snippet | 分组的快捷回复，一键复制。 |
| 星标 Pin | 客户和项目都可以星标，星标的在列表置顶、侧栏有「星标」视图。 |

**不做**：源头厂家、印刷报价、订单明细行、物流、表格导入、多用户、云同步。

## 4. 项目状态

| key | 显示 | 含义 | 颜色语义 |
|---|---|---|---|
| `lead` | 洽谈中 | 还在聊需求/报价 | 紫灰 |
| `active` | 进行中 | 正在做 | 蓝 |
| `review` | 待确认 | 发给客户等反馈/改稿 | 琥珀 |
| `delivered` | 已交付 | 最终文件已给到客户 | 青 |
| `done` | 已完成 | 交付且收清，归档 | 绿 |
| `cancelled` | 已取消 | 黄了 | 灰 |

- 看板列：洽谈中 / 进行中 / 待确认 / 已交付 / 已完成（只显示近 30 天完成的，可展开全部）。已取消不进看板，在列表筛选可见。
- 状态改到 `delivered` 自动写 `delivered_at`；改到 `done` 写 `completed_at`。
- 若状态为 `delivered` 且已收清，项目卡片上提示「可以标记完成」（不自动改）。

## 5. 钱的规则（全部以「分」为整数存储）

- 项目：`price_cents` 报价/应收；`cost_cents` 成本（材料、外包、印刷等，可为 0）。
- 收款：`kind = income | refund`，金额永远为正数。
- 已收 = Σincome − Σrefund；待收 = max(price − 已收, 0)；利润 = 已收 − 成本（收入页另给「预计利润」= price − cost）。
- 收款状态（派生，不入库）：`unpaid` 未收 / `partial` 部分 / `paid` 已收清 / `over` 多收。
- `cancelled` 项目不计入待收。
- 记收款时金额超过待收要二次确认（「将多收 ¥X，确定吗？」），不是禁止。
- 显示：`¥1,280` 无小数时不显示 `.00`；有分时显示两位。数字列等宽数字。

## 6. 信息架构

左侧导航（可折叠到图标栏）：

```
[应用标志] 客户工作台
──────────
今日          Ctrl+1
项目          Ctrl+2
客户          Ctrl+3
收入          Ctrl+4
文件          Ctrl+5
话术          Ctrl+6
──────────
视图
  ★ 星标
  ⚠ 逾期        (数量)
  ¥ 待收款      (数量)
标签
  ● 老客户 12
  ● 餐饮   5
  …（可折叠，点击 = 打开项目页并按该标签筛选）
──────────

```

全局：`Ctrl+K` 命令面板；`Ctrl+N` 新建项目；`Ctrl+Shift+N` 新建客户；`Esc` 关闭面板/弹窗；`/` 聚焦当前页搜索。

## 7. 页面

### 7.1 今日

目标：5 秒内知道今天要干什么、钱的状况。

- 顶部：问候 + 日期（「周一，11月2日」）+ 一句总结：「3 个项目进行中，2 个本周到期，还有 ¥1,280 待收」。右侧大按钮「新建项目」。
- 左栏（主）：
  - **需要关注**：逾期 + 3 天内到期的项目（逾期在前），卡片式：客户头像、项目名、状态、到期相对时间（「逾期 2 天」红、「明天」琥珀）、金额。全部清空时显示一个轻松的空状态插画「今天没有着急的事」。
  - **进行中**：按状态分组（进行中 / 待确认 / 洽谈中）的紧凑列表，每行可直接下拉改状态。
- 右栏：
  - **本月收入**：大数字 + 环比上月 + 近 6 个月迷你柱状图。
  - **待收款**：按金额排序前 5，行尾「记一笔」快捷按钮。
  - **最近动态**：最近 10 条 activity。

### 7.2 项目

- 页头：标题「项目」+ 计数；视图切换 `列表 | 看板`（记住选择）；搜索框；「新建项目」。
- 筛选条（可组合，显示为可删除的 chip）：状态（多选）、标签（多选，AND）、客户、收款状态、截止日（逾期 / 本周 / 本月 / 无截止日）、来源平台。侧栏「视图」「标签」点进来就是预设筛选。
- 排序：截止日（默认，空值在后）/ 最近更新 / 金额 / 创建时间。
- **列表**：行高 40px。列：★ | 项目名（下方小字客户名+头像）| 状态 pill | 标签 | 截止日 | 金额 | 收款进度（细进度条 + 已收/报价）| 更新时间。行右键菜单：改状态、打标签、记收款、打开文件夹、星标、删除。键盘 ↑↓ 移动、Enter 打开。
- **看板**：dnd-kit 拖动卡片换列（换列=改状态，写动态）。卡片：项目名、客户头像+名、标签色点、截止日 chip、金额与收款状态小徽标、文件数。列头显示数量与金额合计。
- 点击项目 → 右侧滑出 **项目详情面板**（宽 600px，可拖宽，可「在整页打开」）。列表/看板仍在左侧可见、可继续点别的项目。

### 7.3 项目详情（面板与整页共用同一组件）

- 头部：项目名（点击即编辑）、客户（链接到客户）、状态下拉、★、更多（复制项目、打开文件夹、删除）。
- 属性区（两列紧凑表单，点击即编辑、自动保存）：截止日、开始日、来源平台 + 平台订单号（带复制按钮）、标签选择器。
- **钱卡片**：报价 / 成本 / 预计利润；已收 / 待收 + 进度条；收款流水（日期、方式、金额、备注，可编辑/删除）；「记一笔」行内表单（金额默认填待收，日期默认今天，方式记住上次选择：微信/支付宝/淘宝/闲鱼/银行转账/现金/其他）；「退款」次级入口。
- 选项卡：
  - **文件**（默认）：见 §8。
  - **动态**：顶部输入框（Ctrl+Enter 发送），下方时间线，手写备注可编辑/删除，系统记录灰色小字。
  - **需求**：大文本区，记录需求说明/尺寸/文案/要求，自动保存。

### 7.4 客户

- 左右两栏：左客户列表（宽 320px），右客户详情。
- 列表：搜索（姓名/电话/微信/平台账号/备注）、标签筛选、排序（最近合作 / 累计金额 / 名称 / 创建时间）。项：头像（姓名首字 + 稳定配色）、姓名、标签色点、「3 个项目 · ¥2,400」、最近合作相对时间。星标置顶。
- 详情：
  - 头部：头像、姓名（可编辑）、公司/店铺名、星级（0–5，点击设置）、标签、★、更多（删除）。
  - 联系方式卡：电话、微信、邮箱、平台账号（多个：平台 + 账号名）、地址；每项旁边复制按钮；空的项不显示，「＋ 添加联系方式」。
  - 数据条：项目数、累计收款、待收、首次合作、最近合作。
  - 选项卡：**项目**（此客户所有项目，紧凑列表 + 「为他新建项目」）| **文件**（客户资料文件夹 + 各项目文件汇总）| **动态**（客户备注 + 其项目动态汇总）。
- 新建客户：弹窗，只有「名称」必填，其余可选；可在新建项目的客户选择框里直接输入新名字创建。

### 7.5 收入

- 时间范围：本月 / 上月 / 本季度 / 今年 / 去年 / 全部 / 自定义。
- 指标卡：实收、待收、成本、利润、成交项目数、客单价。每个带与上一周期对比。
- 图：近 12 个月每月实收柱状图 + 利润折线（悬停看数值）。
- 待收款项目表：客户、项目、报价、已收、待收、截止日、「记一笔」。
- 收款流水：日期、客户、项目、方式、金额（退款显示负数红色），可按方式筛选，可导出 CSV。
- 客户排行：本周期实收前 10。

### 7.6 文件

- 全文件库最近文件（按修改时间），网格/列表切换。
- 筛选：类型（图片 / 设计源文件 psd·ai·cdr·sketch·fig·indd / PDF / 文档 / 压缩包 / 视频 / 其他）、客户、文件名搜索。
- 卡片：缩略图（图片）或类型图标、文件名、客户 · 项目、大小、时间。双击用系统程序打开；右键：打开、在文件夹中显示、复制路径、跳到项目。

### 7.7 话术

- 左分组列表（可新建/重命名/排序/删除），右该组话术卡片网格。
- 卡片：标题 + 内容前 3 行。点击卡片 = 复制到剪贴板 + toast「已复制」；悬停出现编辑/删除。
- 顶部搜索跨组搜索。命令面板也能搜到话术，回车即复制。
- 内容支持换行，原样复制。

### 7.8 设置

- 文件库：当前位置、可用空间、状态；「打开」「更换位置」（只改指向，提示用户自己移动文件；或「复制到新位置」带进度）。
- 新项目子文件夹模板：默认 `参考资料`、`过程稿`、`交付成品`，可编辑，可关闭。
- 外观：浅色 / 深色 / 跟随系统；侧栏紧凑模式。
- 标签管理：列表（颜色、名称、使用数），改名、改色、合并到另一个标签、删除。
- 收款方式管理：增删排序。
- 备份：每天首次启动自动备份数据库（保留最近 30 份）到 `<文件库>/_备份/`；「立即备份」；「从备份恢复」（恢复前自动再备份一份当前库）。
- 回收站：已删除的客户/项目，可恢复或彻底删除（彻底删除需确认）。
- 关于：版本号、检查更新。

### 7.9 首次启动

一个居中的欢迎页：应用标志 + 一句话 + 「选择文件库位置」（默认建议 `文档\客户工作台`，可改）→ 完成后进入「今日」，今日页空状态引导「新建第一个客户/项目」。

## 8. 文件模型（重要）

**文件夹就是真相**。应用不把文件「存进数据库」，而是管理一个看得见的文件夹结构，并实时列出里面的内容。这样在 Photoshop/AI 里直接「另存为」到项目文件夹，应用里也能马上看到。

```
<文件库>/
  _备份/
  _回收站/
  林女士/                        ← 客户文件夹（创建客户时不建，第一次需要时才建）
    _客户资料/                   ← 名片、logo、二维码等
    2026-11 宣传单设计/          ← 项目文件夹：「YYYY-MM 项目名」
      参考资料/
      过程稿/
      交付成品/
```

- 文件夹名做非法字符清理（`\/:*?"<>|`、首尾空格和点）；重名自动加 ` (2)`。
- 数据库只存客户/项目的 `folder`（相对文件库的路径）。客户/项目改名时提示「同时重命名文件夹？」（默认是），失败不影响记录。
- 拖拽文件进项目详情 / 客户详情 / 看板卡片 / 列表行 → **复制**进对应文件夹（拖到项目详情时可选放进哪个子文件夹，默认根目录或第一个子文件夹）；同名自动编号。也支持「添加文件」按钮选择。
- 文件列表：按子文件夹分组，网格（缩略图）/列表切换，显示名称、大小、修改时间。图片（png/jpg/jpeg/webp/gif/bmp/svg）显示缩略图；其他显示类型图标与扩展名徽标。
- 操作：双击打开（系统默认程序）、在文件夹中显示、重命名、复制路径、删除（移到 `<文件库>/_回收站/` 并保留相对结构，不硬删）。
- 应用窗口重新获得焦点时刷新当前打开的文件列表。
- 文件库离线（盘符不在/没权限）时：不影响客户项目数据，文件区显示明确告警与「重新选择位置」。

## 9. 交互准则

- **一切可就地编辑**，失焦/回车自动保存，失败给 toast 并回滚。没有「保存」按钮的编辑表单（新建弹窗除外）。
- **删除可撤销**：删除客户/项目为软删除，toast 带「撤销」5 秒；回收站可恢复。删除客户会提示其项目数，并一起进回收站。
- **新建项目弹窗**（Ctrl+N）：项目名（必填，自动聚焦）、客户（可搜索的下拉，输入新名字回车即创建客户）、报价、截止日（快捷：今天/明天/3天后/下周一/自定义）、标签、状态（默认进行中）、来源平台。Enter 保存，Ctrl+Enter 保存并继续新建。保存后打开该项目详情。
- **命令面板**（Ctrl+K）：一个输入框同时搜客户、项目、话术、命令（新建项目、新建客户、记一笔收款→选项目、跳转各页、切换主题、打开文件库）。结果分组，↑↓ 选择，Enter 执行。
- **复制无处不在**：电话、微信、平台账号、订单号、文件路径旁都有复制按钮，复制后图标短暂变 ✓。
- **空状态**：每个列表都有友好的空状态（插画 + 一句话 + 主操作）。
- **加载**：骨架屏，不用转圈遮罩。
- **数字**：金额等宽数字、千分位；相对日期用中文（今天、明天、3 天后、逾期 2 天、上周三）。
- **可访问性**：所有图标按钮有 `aria-label` 和 tooltip；焦点环清晰；弹窗可 Esc 关闭并还原焦点；颜色不是唯一信号（状态 pill 有文字）。

## 10. 验收标准（Claude 会逐条检查）

1. 首次启动可选文件库并进入今日页；重启后数据还在。
2. 新建客户 → 新建项目 → 拖入 3 个文件（含图片有缩略图）→ 记 2 笔收款 → 改状态到已完成，全程无需离开项目面板，动态里有完整记录。
3. 看板拖动换列生效、刷新后保持。
4. 标签：创建、改色、给客户和项目打标签、侧栏点击标签筛选、合并标签。
5. 逾期项目在今日页「需要关注」和侧栏计数中正确出现。
6. 收入页数字与手算一致（含退款、已取消项目排除）。
7. 话术点击即复制；命令面板能搜到客户/项目/话术。
8. 删除项目可撤销；回收站可恢复。
9. 浅色/深色两套主题都没有看不清的文字。
10. `npm run build`、`npm test`、`cargo test` 全部通过；`npm run tauri build` 产出安装包。
