# 使用说明

## 日常使用顺序

1. 新建客户，录入常用电话、微信、平台身份和地址。
2. 保存后选择“继续新建订单”，或从顶部“新建订单”进入。
3. 填写设计/交付截止日、项目报价、物流和收货地址。
4. 在订单详情上传文件、调整双进度并记录收款。
5. 工作台优先处理逾期、三天内到期、待设计、待发货和待收款订单。

星级客户在“客户管理”的“星级 VIP”筛选中查看，不再占用单独的一级导航。全局搜索支持 `Ctrl+K`，可查客户、平台账号、订单号、物流单号、厂家与备注。

## 客户表格导入

1. 打开“数据与备份”，选择 `.xlsx`、`.xls`、`.xlsb`、`.ods` 或 `.csv` 文件。
2. 多工作表文件先选择工作表，再把来源列映射到客户字段。
3. 逐行检查名称、VIP 星级和疑似重复项。疑似重复依据规范化后的电话、微信号、平台账号或网名判断。
4. 重复项默认“跳过”，也可以为已有客户选择“更新”，或明确选择“仍然另建”。
5. 确认后整批数据在一个数据库事务中写入；任意一行失败则整批回滚，重复点击同一批次也不会再次写入。

单个文件最多 50 MB、20,000 行数据和 256 列。CSV 支持 UTF-8（含 BOM）和常见中文 GBK 编码。

## 收款与纠错

- 每笔收款必须大于 0。
- 收款超过订单应收时会再次确认，不会静默写入。
- 错误收款可以在订单详情删除；删除后已收、未收和结清状态会重新计算。
- 数据库存储整数分，避免普通浮点金额累积误差。

## 客户文件库

- 上传或拖入文件会复制原文件，原位置内容保留。
- 同名文件自动生成 `(2)`、`(3)` 等名称，不覆盖已有版本。
- 删除附件、订单或客户时，受管文件先移动到文件库的 `_回收站`；需要永久清理时再手动删除。
- 磁盘拔出、网盘目录离线或权限变为只读时，侧栏与设置页会显示真实状态，但业务记录仍可查看。
- 更换文件库请使用“设置 → 安全迁移文件库”。应用复制并校验完成后才切换，旧目录保留供核对。

如果客户二维码更换，下一次建立订单文件夹时，受管的二维码副本会安全替换为最新图片。

## 数据库快照

数据库快照适合日常防误删，包含结构化数据和工作台自定义设置，不包含 PSD、图片等客户文件。

- 应用每天启动时最多自动创建一份，自动备份保留最近 30 份。
- “立即创建快照”和自动备份使用设置页显示的同一目录。
- 恢复前会先创建当前数据库的安全副本。
- 选择器只接受数据库备份类型；恢复会校验 SQLite 完整性和工作台结构。

## 完整归档与迁移

完整归档 ZIP 包含数据库、设置和整个客户文件库。导出时不能保存到客户文件库内部。

恢复步骤：

1. 选择完整归档，等待清单、哈希和数据库完整性检查。
2. 选择一个可写的空文件夹作为新文件库。
3. 核对导出时间、结构版本、文件数量、大小和原路径。
4. 输入“完整恢复”确认。
5. 应用创建当前完整工作区的安全归档，提取并逐个校验文件，再切换数据库和路径。

恢复失败会尝试自动回滚；原文件库不会删除。完成后先核对客户、订单和几个关键文件，再决定是否手动清理旧目录。

## 快捷语和订单模板

快捷语支持主类、小类、搜索、复制、编辑和删除；常用订单项目可以保存为最多 12 个自定义模板。两类自定义内容同时保存在数据库设置和浏览器本地副本中，因此会随数据库快照与完整归档一起备份。

## 隐私提示

应用不会自动上传业务数据。若客户文件库选择 OneDrive、百度网盘等第三方同步目录，文件是否上传由对应网盘客户端决定，请根据客户数据敏感程度配置网盘权限与加密。
