## 契约改动：`files_add` / `files_pick_and_add` 返回部分成功结果
之前只能返回成功列表，失败文件只记在动态里，界面无法即时提示。改为返回：
```ts
export interface FilesAddResult { added: FileEntry[]; failed: { name: string; message: string }[] }
```
- 后端：两个命令返回 `FilesAddResult`；全部失败时也返回 `Ok`（`added` 为空、`failed` 列出全部），只有目标无效/文件库不可用这类整体错误才返回 `AppError`。动态记录保持现状。更新 `docs/spec/ARCHITECTURE.md` 不需要（Claude 会同步），但要在交付说明里写明。
- 前端：`types.ts`、`tauri.ts`、Mock、hooks 同步；拖入/添加后 toast：全部成功「已添加 N 个文件」；部分失败「已添加 N 个，M 个失败」并可展开查看失败文件名与原因。
- 后端 `cargo fmt --check`、`clippy -D warnings`、`cargo test` 必须通过。

## 顺带修复（Claude 验收 2a 时发现）
1. **本月收入环比**：月初拿「本月 1–2 号」和「上月整月」比，永远显示 -99%。改为与上月**同期**比（上月 1 号到上月同一天，上月天数不足按月末截止）；收入页的「较上一周期」同理按同长度区间比较。`lib/stats.ts` 补单测。
2. **今日页「最近动态」**：改为每条一行（彩色小图标块 + 「客户 · 事件」+ 金额/文件数等关键信息 + 右侧相对时间），按 kind 区分图标与色调（收款 mint、文件 sky、状态 violet、备注 peach、创建 amber）；相对时间不要「大约」二字（「4 小时前」「昨天 14:20」）；最多 8 条，与左栏高度大致平衡。Mock 种子的最近动态要混合多种类型，不要全是收款。
3. **收入柱状图纵轴**：用整齐刻度（如 0 / 5千 / 1万 / 1.5万），中文金额缩写格式；或隐藏纵轴只在 tooltip 显示金额，二选一以好看为准。
4. **开发模式 HMR**：Vite 只监听 `127.0.0.1`，而页面与 Tauri `devUrl` 用 `localhost`，导致浏览器控制台 `WebSocket connection to 'ws://localhost:1420/' failed`。统一为一种（推荐 Vite `host: 'localhost'` 或 tauri.conf `devUrl` 改 `http://127.0.0.1:1420` 并配置 `server.hmr.host`），确认 HMR 正常。
