## 完成

- 客户跟进：客户详情新增「跟进」选项卡，支持新建、编辑、关联本客户项目、调整时间、取消、填写结果完成和重新开启。今日页集中显示今日到期及逾期计划，可以直接进入对应客户跟进页。
- 到期提醒：应用运行时每分钟及重新聚焦时检查，使用持久化的提醒版本和原子领取避免刷新、重启或并发检查重复提醒。调整时间或重开后允许再次提醒；已删除客户不提醒，已删除项目对应的计划保留但暂停提醒。
- 客户归档：提供归档、恢复和「常用客户／已归档／全部客户」筛选。归档不删除项目、收款、文件或已有跟进；归档客户仍可用于新建项目。
- 客户合并：先选择保留客户，展示项目、收款、动态、跟进、目录及资料冲突预览，再确认执行。目标已有资料优先，空字段补齐，标签与账号去重，来源备注和冲突值保留；预览后数据变化会拒绝提交并要求重新核对。
- 合并完整性：在同一数据库事务中转移全部项目（包括回收站项目）、动态、跟进和文件索引归属；收款依然关联原项目，不复制金额。来源客户作为合并记录保留，不可从普通回收站恢复或清除。原文件不移动，原客户目录及旧别名继续由目标客户访问。
- 文件版本：右键文件进入「版本历史」，支持保存带备注的当前快照、上传同扩展名新版本、预览／打开／定位历史文件，以及恢复历史版本。替换和恢复前先保留当前内容，快照写入成功后设为只读。
- 文件恢复：文件页「版本与恢复」及设置「备份与回收站」可进入全库历史与文件回收站。回收文件恢复到原位置；遇同名自动编号，不覆盖现有文件；兼容此前未索引的旧回收文件。
- 目录与恢复边界：版本和回收索引跟随客户／项目目录及文件改名；整库搬迁通过库内持久 ID 保持历史，切换其他文件库不混入原库快照。修复中断回收占位阻塞后续操作，以及客户主目录缺失时有效别名资料被隐藏的问题。
- 数据升级：数据库从 v1 事务升级到 v2。旧备份先只读校验、复制到临时数据库并升级，通过后才替换当前库；恢复前生成安全备份。损坏结构、缺少唯一索引、外键异常或未来版本备份会被拒绝，不改现有数据。

## 未完成 / 偏离规格

- 本轮依照用户明确追加的功能范围新增数据表与 API 命名空间；保留既有 Client、Project、FileEntry 类型和原有方法签名，没有修改 `docs/spec/`。新增契约见下方，需 Claude 同步规格。
- 跟进提醒在应用运行时生效，关闭应用后不提供系统后台提醒；再次打开会检查到期计划。界面已明确说明。
- 文件版本由「保存当前版本」或「上传新版本」创建，不会监听外部设计软件的每次保存。数据库备份包含版本和回收索引，不包含文件字节；需同时保存文件库。
- 合并不提供一键撤销。确认前展示影响，保存来源与目标原始资料审计记录；不会自动合并同名客户。
- 未打包、安装或替换现有桌面程序。界面实测使用隔离浏览器 Mock，未改写真实客户数据；原生文件选择器未人工点选，真实文件读写和 Windows 替换失败由 Rust 测试覆盖。
