## 背景：为什么重做
用户看了第一版界面后说：「ui太丑了，我要年轻化的」，并给了一张参考截图（用户自己的另一个应用「素材管理」），要求**「比这个更好看更大气」**。
参考图的特征：
- 浅色、通透，长春花蓝紫（periwinkle / indigo）为主色，大量白色卡片，柔和阴影，大圆角（14–20px）；
- 首页顶部一张**宽幅日系动漫插画横幅**（少女抱着鲸鱼玩偶坐在洒满阳光的白色海边工作室里），横幅左侧叠着大标题「让灵感，在这里轻轻生长。」、一句副标题和一个渐变主按钮；
- 横幅下方三张统计卡片：左侧淡彩色圆角图标块 + 标题 + 小字说明，右侧大号数字；
- 侧栏是白色悬浮面板，选中项是白底胶囊 + 左侧色条，图标线性；
- 整体温柔、年轻、有生活感。

我们要做得**更好看、更大气**：更大的标题与数字、更舒展的留白、更有层次的柔和渐变背景（可以有极淡的彩色光斑）、更精致的插画、更统一的彩色图标块体系，但信息仍然清晰好用（这是每天用的工作软件）。

先读 `docs/spec/PRODUCT.md` 了解功能（应用名「客户工作台」：个人设计师管理 客户 → 项目 → 文件 → 收款，带彩色标签）。界面布局可参考已有的 `docs/spec/concepts/today-light.png`、`projects-light.png`（信息结构对，但风格太素，这次要换成年轻化风格）。
